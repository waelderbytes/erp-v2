# Benutzerhandbuch

Wird parallel zu jedem Modul befüllt (nicht nachträglich am Ende), damit die
Anwenderdokumentation nie hinter dem Code zurückfällt. Speist gleichzeitig
Teil 2 der `docs/compliance/verfahrensdokumentation.md` (GoBD-Anwenderdokumentation).

Struktur pro Modul-Kapitel: Zweck, Voraussetzungen, Schritt-für-Schritt-Anleitung,
häufige Fehler/FAQ.

*Inhalte werden ergänzt, sobald das jeweilige Modul einen nutzbaren Stand erreicht.
Kein Kapitel wird vorab spekulativ befüllt, um keine falsche Anwenderdoku für noch
nicht existierende Funktionen zu erzeugen.*
